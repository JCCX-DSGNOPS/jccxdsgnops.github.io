✨ Features

📦 Material Design 3

100% compliant with MD3 architecture: color system, typography, spacing, shape, elevation, motion.

🎨 Token-Based

All specifications use CSS design tokens. No hardcoded values. Easy to maintain and theme.

♿ Accessible

WCAG 2.1 AA compliant. ARIA roles, keyboard navigation, screen reader support, 44×44dp touch targets.

🎯 13-Section Specs

Each component: identity, purpose, anatomy, variants, specs, states, behavior, composition, guidelines, accessibility, code, related, changelog.

💾 JSON Schema

Validated against JSON Schema 2020-12. Ensures consistency and enables automation.

🔄 Replicable

Patterns documented for extending to all 128 components in NODO system.

🚀 Ready for Agent Training?

This documentation framework enables AI agents to understand component specifications deterministically and generate UI implementations with high fidelity. All components follow the same 13-section pattern, making the system predictable and reproducible.

View Complete Specs →

🔧 Technical Stack

  • Format: JSON Schema 2020-12 validated specifications
  • Design Tokens: CSS custom properties (--nodo-primary, --spacing4, etc.)
  • Architecture: Material Design 3 (2-layer color, 5 typography roles, 4px spacing grid)
  • Accessibility: ARIA attributes, keyboard navigation, semantic HTML, WCAG 2.1 AA
  • Code: Executable HTML + CSS using only design tokens
  • Validation: Python build.py checker (C01-C25 validation suite)
